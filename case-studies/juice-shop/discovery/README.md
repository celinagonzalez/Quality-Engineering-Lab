# Discovery — OWASP Juice Shop

This folder contains the business discovery evidence produced during
Sprint 0–1, under US-001 - Understand the Business Domain.

Discovery follows a black-box, business-first approach: no source
code analysis is performed, and no test scenarios are produced here
— the goal is to build a validated understanding of the business
domain before test design begins.

## Findings Classification

All findings across discovery documents are classified using a
consistent status:

- **Confirmed** — backed by official documentation or direct evidence.
- **Observation** — directly observed in the application.
- **Hypothesis** — an interpretation that still needs validation.
- **Open Question** — cannot be determined yet; tracked in its own
  section per document.
